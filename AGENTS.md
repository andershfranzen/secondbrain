# Project instructions

Use Taste Skill v2 (`design-taste-frontend`) for interface work. Read
`docs/interface.md` for the accepted direction and deliberate exceptions.

The landing page is essentially one input box. Capture, recall, and earlier
conversations share that workspace. Do not add dashboard cards, greetings,
suggested prompts, motivational copy, or separate Capture/Recall/History tabs.
Keep memory processing, provenance, correction, and retry behavior capable behind
this simple interface. Never promote an assistant answer or a question into a
factual memory. Preserve originals before running AI.
